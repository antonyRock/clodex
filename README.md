# Clodex

Все чаты **Claude Code** и **Codex** в одном списке в VS Code: поиск по тексту внутри чатов, непрочитанные, активные, группы.

*One sidebar for all your Claude Code and Codex chats in VS Code: full-text search, unread markers, an Active filter, groups. Local only, nothing is sent anywhere.*

## Что умеет
- **Поиск по тексту** внутри чатов, а не только по названиям, с подсветкой найденного.
- **Статусы:** красная мигающая точка — агент ответил, а вы ещё не открывали; жёлтая — агент работает; серая — прочитано. Число непрочитанных — на иконке Clodex и в строке состояния.
- **Вернуться позже:** правая кнопка на чате → «Отметить непрочитанным» (или клик по серой точке) — чат мигает, пока не откроете его снова.
- **Фильтры:** четыре плитки одного размера со своими значками — «Недавние» (все чаты, свежие сверху), «★ Избранное», «⚡ Активные» (агент работает, ответ не прочитан или чат был за последние 2 часа), «Жду ответа»; число — в углу плитки. Повторное нажатие на выбранную плитку — по группам или списком. Счётчик «N новых» в заголовке — фильтр непрочитанных. Воронка в заголовке открывает меню: чьи чаты показывать (Claude, Codex или оба) и «Архив» с числом чатов; открытый архив — полоса под плитками с крестиком для выхода.
- **Группы:** берутся из групп Claude Code, раскладываются по проектам рабочей папки (необязательно), свои — значком папки с плюсом в заголовке; переименовать, объединить, удалить (чаты остаются), перетащить, раскрыть и свернуть все одной кнопкой. При наведении на группу: ☆ — в избранное (звезда становится жёлтой), значок архива — вся группа в архив; в архиве — вернуть всю группу.
- **Избранное:** звёздочка у чата (поменьше) и у группы. Фильтр «★ Избранное» по группам показывает избранные группы и отмеченные чаты; повторное нажатие — только отмеченные чаты списком.
- **Чат:** открыть по клику, переименовать, убрать в архив, перенести в группу (в том числе перетаскиванием). Новый чат — две большие кнопки «Claude +» и «Codex +» под поиском; «+» при наведении на группу — новый чат сразу в этой группе.
- **Вес чата:** метка «Nk» — сколько контекста агент перечитывает с каждым сообщением; жёлтая от 100 тыс. токенов, красная от 200 тыс. Длинный чат расходует больше токенов — новую задачу лучше начинать в новом чате.
- **Продолжить в новом чате:** стрелка у тяжёлых чатов Claude (или «⋯» → «Продолжить в новом чате») открывает новый чат в той же группе; в поле ввода уже вписан короткий текст: название, последний вопрос, конец ответа и путь к старому чату. Отправляете сами.
- **Один агент — тоже работает:** не установлен Claude Code или Codex — его кнопки серые с подсказкой, остальное работает; появится — кнопки оживут без перезапуска.
- **Текущий чат:** подсвечен открытый сейчас чат Claude (по активной вкладке); чат Codex — после открытия через Clodex.
- **Тема:** кнопка ☀/☾ переключает тему всего VS Code (Light Modern ↔ Dark Modern, настройки `clodex.lightTheme` / `clodex.darkTheme`). Логотипы Claude и Codex берутся из их установленных расширений.

## Установка
Нужны macOS, VS Code 1.90+ и расширение Claude Code и/или Codex.

1. Скачайте `clodex-<версия>.vsix` со страницы [Releases](https://github.com/antonyRock/clodex/releases/latest).
2. Установите:
   ```
   code --install-extension ~/Downloads/clodex-0.9.10.vsix
   ```
   Или в VS Code: Extensions → «⋯» → Install from VSIX…
3. Перезагрузите окно: Cmd+Shift+P → «Developer: Reload Window». Слева появится иконка Clodex.

Обновление — так же, новым файлом из Releases.

## Что читает и что меняет
- **Только читает:** историю Claude Code (`~/.claude/projects/`), Codex (`~/.codex/sessions/`, `~/.codex/session_index.jsonl`), группы и архив Claude Code из базы состояния VS Code (`sqlite3`, только чтение).
- **Автогруппы (необязательно):** если есть файл `~/Claude_AI/03_Проекты/00_Реестр проектов.md` (таблица проектов с колонкой «Признаки: слово, слово»), чаты раскладываются по проектам. Другой путь — настройка `clodex.registryPath`. Файла нет — автогрупп нет.
- **Ничего не отправляет в интернет** и не меняет чаты. Архив, переименования и свои группы хранятся только в Clodex.
- Открывает чаты командами самих расширений Claude Code и Codex.

## Ограничения
- Отметку «прочитано» Clodex ведёт сам. Чат Codex, открытый не через Clodex, останется красным, пока не откроете его через Clodex или не нажмёте на точку. Открытие чата Claude во вкладке Clodex замечает сам.
- При первом запуске все чаты считаются прочитанными.
- Формат истории Claude Code и Codex не документирован и может поменяться — тогда понадобится новая версия Clodex.
- Проверено на macOS. Windows и Linux не проверялись (путь к базе состояния VS Code задан для macOS).

## Сборка из исходников
Зависимостей нет — чистый JavaScript.
```
python3 build.py            # собрать dist/clodex-<версия>.vsix
python3 build.py --install  # собрать и установить
```
